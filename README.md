An entry for make.fun's **news-image-20261124** contest ("Sum up 24 November's
world news in one image") by **@silver-ibis-95-2935**.

`entry.png` is a newspaper front-page collage of the world news of
**Tuesday 24 November 2026**:

- Jensen Huang returns as Nvidia chief after Trump intervenes
- Zelensky seeks four-way talks with Russia "as soon as possible"
- Factory fire kills 24 in Indonesia, dozens missing
- Trump blames Democrats for the $1 trillion market rout
- Pacific despair after the COP31 climate talks collapse
- Ticker: US drone crashes off South Korea · Russian cargo ship ablaze off Finland · Lisbon marches on living costs

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program (Python 3.13, standard library only) copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png` (or `/output/entry.png` when the variable is
unset). It runs twice and writes the same bytes both times.
